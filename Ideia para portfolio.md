# Portfólio pessoal — Ecossistema Nocturne

## Objetivo

Criar um portfólio pessoal moderno para apresentar minha trajetória como desenvolvedor Full Stack, minhas habilidades técnicas e os principais projetos que desenvolvi.

O foco principal será o ecossistema **Nocturne**, destacando projetos como o **Nocturne Codex** e o **Nocturne Control**, além de outros projetos pessoais, como o **SysMon**.

O site também terá acesso direto ao meu GitHub, permitindo que visitantes, recrutadores e outros desenvolvedores possam visualizar meus repositórios, código-fonte e evolução técnica.

## Identidade visual

O portfólio terá uma identidade visual inspirada no universo Nocturne, utilizando:

* Tema escuro;
* Tons de roxo, preto e cinza;
* Elementos com transparência;
* Iluminação suave;
* Gradientes discretos;
* Detalhes visuais que transmitam tecnologia, profundidade e modernidade.

A interface deve ter personalidade própria, sem parecer apenas mais um template genérico de portfólio.

## UI, UX e interface

A interface terá um estilo moderno e minimalista, com animações simples e suaves que melhorem a experiência sem prejudicar a navegação ou a performance.

Entre os principais efeitos visuais estarão:

* Glassmorphism;
* Painéis com aparência de vidro;
* Reflexos e transparências inspirados nas interfaces da Apple;
* Efeito de desfoque no plano de fundo;
* Animações durante a rolagem;
* Transições suaves entre seções;
* Slides para apresentação dos projetos;
* Efeito de profundidade em cards;
* Pequenos movimentos de acordo com a posição do cursor;
* Feedback visual ao passar o mouse sobre botões, links e projetos.

As animações devem complementar o conteúdo, evitando efeitos exagerados que possam distrair o usuário.

## Estrutura do portfólio

### Início

Uma apresentação curta contendo meu nome, minha área de atuação e uma frase que represente meu perfil como desenvolvedor.

Exemplo:

> Desenvolvedor Full Stack criando aplicações, ferramentas e experiências digitais com identidade própria.

A seção inicial também terá botões para acessar meus projetos, GitHub e formas de contato.

### Sobre mim

Uma breve apresentação sobre minha trajetória, meus objetivos profissionais e meu interesse por desenvolvimento de software.

O texto deve destacar minha curiosidade por entender como sistemas funcionam e meu interesse em construir soluções próprias, indo além de apenas utilizar ferramentas prontas.

### Projetos em destaque

Uma área visual dedicada aos meus principais projetos.

Cada projeto poderá ser apresentado em um slide ou card contendo:

* Nome;
* Descrição;
* Imagem ou demonstração;
* Tecnologias utilizadas;
* Principais desafios técnicos;
* Funcionalidades;
* Link para o GitHub;
* Link para demonstração, quando disponível;
* Status atual do projeto.

Os projetos Nocturne terão maior destaque visual por representarem a principal identidade do portfólio.

### Ecossistema Nocturne

Uma seção específica para apresentar o conceito por trás do Nocturne e mostrar como os projetos se relacionam.

#### Nocturne Codex

Aplicação desktop desenvolvida com Electron e React, criada para organização de conhecimento, projetos, decisões técnicas e contexto de desenvolvimento.

O projeto utiliza uma arquitetura segura, mantendo o renderer isolado do Node.js e realizando o acesso a recursos nativos por meio de uma fronteira IPC controlada.

#### Nocturne Control

Interface web relacionada ao universo Nocturne, utilizada para explorar conceitos visuais, componentes e experiências de controle em uma identidade dark.

### Outros projetos

Além do ecossistema Nocturne, o portfólio também apresentará outros projetos pessoais, demonstrando experiência com diferentes linguagens, tecnologias e tipos de aplicação.

Entre eles:

* SysMon, desenvolvido em Rust;
* Projetos web;
* Futuros projetos desenvolvidos em Python.

## Experiência do usuário

O site deverá ser totalmente responsivo e funcionar corretamente em computadores, tablets e celulares.

Também deverá considerar:

* Navegação simples;
* Textos fáceis de ler;
* Bom contraste;
* Animações reduzidas para usuários que preferem menos movimento;
* Carregamento rápido;
* Compatibilidade entre navegadores;
* Acessibilidade;
* Organização clara das informações.

## GitHub e contato

O portfólio terá integração visual com meu GitHub, mostrando os repositórios mais relevantes e oferecendo acesso direto ao meu perfil.

Também terá uma seção de contato com links para:

* GitHub;
* LinkedIn;
* E-mail;
* Currículo.

## Resultado esperado

O resultado deve ser um portfólio profissional, moderno e marcante, capaz de demonstrar não apenas as tecnologias que utilizo, mas também minha forma de pensar, minhas decisões técnicas e minha evolução como desenvolvedor.

Mais do que listar projetos, o portfólio deverá apresentar a identidade do ecossistema Nocturne e transmitir a sensação de que cada projeto faz parte de algo maior.
